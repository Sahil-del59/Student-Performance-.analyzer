# Student Performance Analyzer

A Python command-line utility designed to process, analyze, and evaluate student academic scores using robust file handling and data computation techniques.

## Features
* **Data Ingestion:** Securely reads student score records and datasets from local text or data files.
* **Performance Calculations:** Computes key metrics including class averages, highest/lowest scores, and performance distribution.
* **Automated Reporting:** Generates clean, formatted text summaries to track academic progress efficiently.
